# 🔥 MOLE FEVER (몰 피버) - 2D 아케이드 두더지 잡기 웹 게임

> **Block Blast** 스타일의 정돈된 모바일 그리드 UI와 현대적인 아케이드 네온 시각 효과를 결합한 고품질 2D 두더지 잡기 웹 게임입니다.

---

## 🌟 주요 특징

1. **완전 독립 실행 (Zero Dependency)**
   - 외부 라이브러리, 유료 API, 데이터베이스 없이 브라우저에서 단독 실행 가능
   - CSS & SVG 기반의 사랑스럽고 세련된 오리지널 2D 두더지 캐릭터
   - Web Audio API 내장 합성 사운드 엔진 (외부 음원 파일 없이 즉시 재생)

2. **30초 스릴 넘치는 게임 플레이**
   - 3x3 (9개) 깊이감 있는 3D 입체 홀 구조
   - 편향 없는 무작위 두더지 등장 알고리즘 (연속 동일 구멍 방지)
   - 중복 타격 방지 및 터치/클릭 완벽 분리

3. **4단계 콤보 & 동적 비주얼 시스템**
   - **Tier 1 (0~4 COMBO)**: 차분한 네이비 배경 & 블루 앰비언트 조명 (두더지 노출: 1.3초)
   - **Tier 2 (5~9 COMBO)**: 블루-퍼플 그라데이션 & 네온 보더 (두더지 노출: 1.1초)
   - **Tier 3 (10~19 COMBO)**: 핑크 & 시안 네온 배경 & 파티클 팝업 (두더지 노출: 0.9초)
   - **Tier 4 (20+ COMBO) — FEVER MODE**: 
     - 역동적인 무지개빛 그라데이션 & 골드 네온 효과
     - 두더지가 황금 왕관을 착용하고 **잡을 때마다 2점 획득**!
     - 20~29 콤보: 0.75초 / 30+ 콤보: 0.65초 (최고 속도)

4. **Web Audio API 사운드 시스템**
   - 팝업음, 타격음, 피버 타격음, 미스(놓침) 사운드, 콤보 마일스톤 팡파르, 피버 발동음, 5초 긴급 틱음, 게임오버 징글
   - 소리 켜기/끄기 토글 버튼 지원 (설정 자동 저장)

5. **기록 저장 및 반응형 지원**
   - 최고 점수(High Score) 및 최고 콤보(Max Combo) `localStorage` 자동 보관
   - PC 데스크톱 마우스 클릭 지원 (중앙 아케이드 캐비닛 프레임)
   - 모바일 세로/가로 화면 완벽 대응 (안전 여백 `viewport-fit=cover`, 노치 지원)
   - `prefers-reduced-motion` 모션 감소 접근성 지원

---

## 🚀 실행 방법

### 방법 1. 브라우저에서 바로 열기 (가장 간단)
- 프로젝트 폴더의 `index.html` 파일을 더블클릭하여 크롬, 엣지, 사파리 등의 브라우저로 바로 실행합니다.

### 방법 2. 내장 로컬 서버로 실행 (권장)
터미널에서 아래 명령어를 실행한 후 웹 브라우저에서 접속합니다:
```bash
node dev-server.js
```
접속 주소: **http://localhost:3000**

---

## 🎮 게임 조작법
- **게임 시작**: 화면 하단의 `게임 시작` 버튼 클릭
- **두더지 잡기**: 나타난 구멍의 두더지를 클릭(PC)하거나 터치(모바일)
- **도움말**: 상단 우측 물음표(`?`) 버튼 클릭 시 게임 룰 팝업 표시
- **소리 제어**: 상단 우측 스피커 아이콘 버튼으로 음소거 토글
